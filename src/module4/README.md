# Модуль 4 — веб-кабинет агронома (Precision Ag Stress Detector)

Дашборд на Streamlit: KPI экономии, спутниковая карта Folium с картой-предписанием VRA
и растрами индексов (NDVI / NDRE / MSAVI / NDMI), динамика индексов по датам (Plotly),
баннер раннего стресса, скачивание GeoJSON и Shapefile для трактора.

## Запуск (Python 3.10+)

```bash
pip install -r requirements.txt
python generate_mock_data.py      # создаёт mock_data/ (6 недель, тестовое поле)
streamlit run app.py
```

## Источники данных

В боковой панели переключатель «Источник данных»:

- **Данные проекта (data/)** — папка `data/` репозитория; ищется автоматически вверх от `app.py`
  (до 4 уровней), поэтому модуль можно положить, например, в `modules/module4/`.
  Можно задать явно: `PAS_DATA_DIR=путь/к/data`.
- **Мок-данные** — `mock_data/` из `generate_mock_data.py`.

По умолчанию выбирается первый источник, где есть хотя бы одна дата.

## Что читается (всё необязательно — дашборд показывает то, что уже есть)

| Файл | Модуль | Использование |
|---|---|---|
| `field_boundary.geojson` или `samples/field_boundary.geojson` | M1 | контур поля, центрирование карты |
| `stats/index_stats_YYYY_MM_DD.json` (schema 1.1/1.2) | M2 | `mean_ndvi/ndre/msavi/ndmi` → график; `early_stress_alert`, `early_stress_area_ha/percent`, `early_stress.reasons` → баннер; `indices.*.p5/p95` → единая цветовая шкала на сезон; `zones.classes[].area_ha` → экономика, пока нет M3; `files.*` → пути к растрам |
| `indices/{NDVI,NDRE,MSAVI,NDMI}_YYYY_MM_DD.tif` | M2 | слои индексов (перепроецируются из UTM в WGS84) |
| `zones/zones_YYYY_MM_DD.tif` | M2 | растровая карта зон, пока нет полигонов M3 |
| `vra/` или `prescriptions/` или корень: `prescription_*.geojson`, `shapefile_*.zip`, `metrics_*.json` | M3 | полигоны с нормами, скачивание файлов, экономика |

Норма зоны в GeoJSON читается из `fertilizer_rate` (как в `data/README.md`) или `rate_kg_ha`.
Экономика пересчитывается под слайдеры: норма зоны = базовая норма × `rate_factor`
(если `rate_factor` нет в `metrics_*.json`, он считается как норма зоны / `base_rate_kg_ha`;
если нет и этого — 100% / 53% / 0% для зон 1 / 2 / 3).

## Проблемы с данными

Дашборд показывает то, что смог прочитать, но ничего не подменяет молча: всё, что пропущено или
подставлено по умолчанию, перечисляется в блоке «⚠️ Проблемы с данными» вверху страницы.
Примеры: битый JSON или GeoTIFF, некорректная дата в имени файла, зона без `zone_class`/`area_ha`
или с классом не из 1–3, GeoJSON не в EPSG:4326 (например, в UTM), `metrics_*.json` без
`base_rate_kg_ha` (базовой принимается максимальная норма зоны) или без норм зон (подставляются
100% / 53% / 0%), предписание не в килограммах (экономика не считается), нет средних индексов
для графика. Если в `index_stats` нет флага `early_stress_alert`, вместо зелёной плашки
показывается предупреждение «статус неизвестен».

## Слои из PNG (М1, `overlays/`)

Если есть `overlays/{INDEX}_YYYY_MM_DD.png` и `overlays/meta.json` с `bounds`, слой берётся из PNG
(раньше tif М2). Слои RGB («Снимок Sentinel-2») и HIDDEN («Скрытый стресс М2») есть только в PNG.
PNG накладываются с непрозрачностью 1 (альфа уже в картинке), tif — 0.85. Шкала легенды PNG-слоя
берётся из `meta.index_ranges`. Подписи и цвета легенды — из схемы 1.1: `nodata_label`/`nodata_css`,
`hidden.label`/`hidden.css`, `rgb.legend_text`; для схемы 1.0 — из `nodata_color`, `hidden.color` и
подписей по умолчанию. Если PNG за дату нет, а `meta.json` есть, под картой пишется, что слой построен по
`indices/*.tif`.

## Даты с ошибкой последнего запуска

Если в `pipeline_report.json` у даты есть ошибка (`errors["YYYY-MM-DD"]`), её файлы остались от прошлого
запуска. Дата не прячется, но над картой выводится красный баннер с этапом и текстом ошибки, а скачивание
предписания за неё отключается.

## Стыковка с M3: сезон 2026

M3 передаёт параметры `base_rate_kg_ha`, `price_per_kg` и точные `rate_factor`.
Кабинет также читает прежние `base_rate`, `price_per_unit`. Нормы не округляются
перед расчётом, перерасход показан отрицательной экономией. Нулевая база даёт
неопределённый процент экономии; исходные нормы сохраняются фиксированными.
Литровые предписания не отображаются как килограммовые.

При наличии `coverage` отображаются полный контур и неизвестная площадь;
KPI площади показывает классифицированную часть поля. М2 заполняет классы
облачных участков по ближайшим зонам; они включаются в нормы и экономику.
При `filled_area_ha > 0` из статистики М2 кабинет показывает отдельное
предупреждение о восстановлении. Оставшиеся nodata во входной маске не
получают назначения. Денежные KPI отображаются до копеек.

Слайдер нормы служит для моделирования. Если нормы на экране отличаются от
исходного задания, кнопки скачивания отключаются до возврата нормы или генерации
нового задания в M3. Изменение цены не меняет геометрию и нормы, поэтому скачивание
остаётся доступным. Эта поправка подготовлена вместе с интеграцией M3 и требует
просмотра ответственным за M4.
